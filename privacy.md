# Privacy Policy

This Chrome extension provides Simplified Chinese translations for the Archive of Our Own (AO3) website interface and content.

## Data Collection

The extension developer does not collect, store, or sell users' personal data through this extension.

## Website Content

The extension reads text from AO3 pages in order to provide interface localization and translation features.

Common interface localization is performed locally in the browser using the extension's built-in dictionary.

When a user actively requests Google translation, the relevant work text, summary, notes, or policy text is sent to Google Translate solely for the purpose of generating a translation.

## Data Storage

This extension does not use a developer-operated server to store AO3 page content, machine-translated text, browsing history, or user activity.

## Third-Party Services

Text requested for translation may be sent to Google Translate services solely for the purpose of generating translations.

## Changes

This privacy policy may be updated if the extension's functionality changes in the future.

## Contact

If you have any questions about this extension, please contact the developer through the Chrome Web Store listing.
