Privacy Policy for AO3 Chinese Translator Extension

This extension translates the Archive of Our Own (AO3) interface and selected work content into Simplified Chinese.

Data Collection
The developer of this extension does not collect, store, sell, or share users' personal information.

Website Content
The extension reads text content from AO3 pages in order to translate interface elements and selected content.

Common AO3 interface translation is handled locally in the browser using the extension's built-in dictionary.

When the user clicks a translation button for chapter text or author notes, the relevant text may be sent to Google Translate services solely to generate translated text.

Data Storage
No user data or browsing data is stored by the developer.

Third Parties
The extension may send selected text content to Google Translate APIs solely for translation purposes.

User Control
Chapter and author note translation actions are triggered by the user. The extension only sends text to Google Translate when a translation feature is used.
